## 2. 通用语步骨架（HOOK/FRAME/CONTEXT/ARGUE/COUNTER/APPLY/CLOSE）

[标注-3篇] 基于 fde-role-renaissance（38 段）+ glm-5-3-analysis（48 段）+ multi-agent-sociology（45 段）共 131 段标注聚合；ARGUE 占比 64%，COUNTER 7 处全部来自行业分析篇，HOOK 全库仅 1 例，叙事段占比 12%。

```
HOOK（可选，仅行业分析用场景并置；报告体/期刊体禁止，以元信息头/摘要替代）
→ FRAME（必选项一：元信息头+摘要 / 摘要+关键词 / "本文解答 N 个问题"清单——开场必有框架性预告）
→ CONTEXT（概念定义、事件背景、历史叙事；叙事只允许出现在这里，叙事比 0.3–0.6）
→ ARGUE×n（主体 ≈2/3 篇幅；数据锚定 / 官方口径引用 / 多方引语对比 / 机制分析推进）
→ COUNTER（行业分析必备独立反驳节；报告体以"局限声明/口径澄清"内化；期刊体以"局限声明"收尾前置）
→ APPLY（判断标准清单 / 操作判据，如"四项标准，缺一即败"）
→ CLOSE（编号结论 + 展望 / 后续问题清单 / 局限声明+研究议程 / 系列预告+信源征集）
```

写作指令：
1. 开场三段内必须完成"框架预告"——告诉读者本文解答几个问题、分几层展开（实证：FRAME×5 连排是报告体开场指纹）。
2. ARGUE 段落每个论断挂证据（实证配比 evidence_per_claim = 1.8，见 §5）；叙事段落压到起源/场景节内，论证节叙事比归零。
3. 反驳显式列出并标注处理结果（rebutted / left-open），未解决的不装作已解决。
4. 小节结尾允许比喻回收（"修路队就会收缩，但修路不会结束"），全文 CLOSE 区禁止重复段（FDE 篇 para 36 教训）。

## 7. 操作化模式（该库固定招式）

[标注-3篇] 招式 1–4 经标注实证；[推断] 招式 5–6 仅档案散文支持。

1. **明示 N 问题清单**：开场直书"本文将解答三个问题"，后文逐题对应编号章节。
2. **信源分层标注**：官方（锚点）→ 第三方（数据）→ 社区（案例）三层显式区分；报告体以附录实体化（已核实/修订澄清/待确认三档）。
3. **判断带边界**：凡结论句带数量/范围限定（"大多数""三种""缺任意一项"），克制比 ≈ 1:3（断言型 1.05 : 限定语 3.12，统计层口径）。
4. **编号结论 + 开放问题**：收尾不收死——报告体留"后续关注问题清单"，期刊体留"局限声明+研究议程"，行业分析留"系列预告+信源征集"。
5. **单一比喻全文复用**：修路/壳/笼子式比喻服务概念而非情绪，小节结尾回收（档案 §5，待标注验证）。
6. **中英混排术语纪律**：英文原词保留，首现括注中文译名，全文唯一译名（档案 §5，统计层以 en_char_ratio 0.25 间接支持）。**英文成稿时反向适用，见 §0。**
