## 摘要

DeepSeek-V4 是深度求索继 V3 系列之后推出的新一代通用大模型主线迭代。2026 年 4 月 24 日，DeepSeek 发布《DeepSeek-V4 技术报告》并同步推出预览版 API，形成 **V4-Pro（1.6 万亿参数）** 与 **V4-Flash（2840 亿参数）** 的双版本体系，全系标配 **100 万（1M）Token 上下文窗口**。

经过约三个月的后训练打磨，**V4-Flash 正式版（DeepSeek-V4-Flash-0731）** 于 2026 年 7 月 31 日上线公测，Agent 能力大幅增强，原生支持 Responses API 并适配 Codex。**V4-Pro 正式版（DeepSeek-V4-Pro-0813）** 于 2026 年 8 月 13 日发布，同样完成 Agent 能力升级，并引入 low / high / max 三档思考模式。

本报告的核心判断是：V4 系列以“**架构创新 + 后训练优化 + 极致性价比**”为核心竞争力，在编程、Agent 与长文档处理方面表现突出；但其纯文本定位、多模态能力短板以及定价策略的频繁调整，仍是影响长期市场表现的关键变量。

## 一、概述

### 1.1 产品定位

DeepSeek-V4 采用“**代际（V4）+ 能力层级（Pro / Flash）**”的双版本体系：

- **V4-Pro**：旗舰顶配，面向企业级复杂科研、重度开发、超高难度逻辑任务；硬件与调用成本较高。
- **V4-Flash**：轻量普惠版本，面向实时对话、函数调用流水线、长文档处理、高并发商业场景；强调提速降价与低硬件门槛。

官方在 V4 官宣文稿末尾引用《荀子·非十二子》中“**不诱于誉，不恐于诽**”，呼应其“优先突破技术边界、而非短期商业化”的路线。

### 1.2 发布与迭代状态

- **V4-Flash 正式版**：2026 年 7 月 31 日上线公测，模型编号 DeepSeek-V4-Flash-0731。
- **V4-Pro 正式版**：2026 年 8 月 13 日发布，模型编号 DeepSeek-V4-Pro-0813；发布初期曾出现短暂“回滚 / 降智”争议。
- 二者均为纯文本模型，已开源（MIT 协议）。

## 四、核心技术与新特性

### 4.1 混合注意力机制（CSA + HCA）

V4 采用双层交替注意力设计，以突破长上下文算力瓶颈：

- **CSA（压缩稀疏注意力）**：每 4 个 Token 压缩为 1 个 KV Cache Entry，查询仅与 Top-K 压缩块交互。
- **HCA（层级上下文注意力）**：每 128 个 Token 压缩为 1 个 Entry，保留稠密计算。
- **效能表现**：在 1M 上下文下，V4-Pro 单 Token 推理计算量降至 V3.2 的约 **27%**，KV 缓存占用降至约 **10%**；V4-Flash 分别降至约 **10% 与 7%**，显存占用显著下降。

### 4.2 训练稳定性与关键技术

技术报告提及 **mHC（流形约束超连接）**、**Muon 优化器**、**FP4 低精度训练**等关键技术，用于解决超大规模训练的稳定性与效率问题。

**值得注意的“缺席”**：业界高度期待、由 DeepSeek 与北大在 1 月联合开源的 **Engram（条件记忆查表模块）** 并未进入 V4 正式架构。不过 Engram 的理念已通过后续多篇论文（CXL 内存池化、无冲突热层实验、视觉 Tiny Engram 等）延续，被认为将为下一代模型奠基。

### 4.3 正式版“只调教、不改架构”

V4-Flash 正式版（0731）未修改底层架构与参数规模，模型结构、尺寸与预览版完全一致，主要依靠精细化强化学习与高质量数据重训，实现了工具调用、代码开发、Agent 能力的跨越式提升。这印证了“选对教材、用对方法，轻量模型也能变得很聪明”的技术路线。

### 4.4 降低对英伟达生态的依赖

这是 V4 最具战略意义的创新之一：核心算子深度自研（DeepGEMM 替代 cuBLAS、MegaMoE 自研 mega-kernel 等），大幅降低对英伟达 CUDA 生态的依赖。

需要说明的是，“完全脱离 CUDA”属于夸张表述；实际仍主要基于 CUDA 生态，但自研算子使国产 GPU、通用算力卡无需厂商定制适配即可直接部署。技术报告同时提及华为昇腾与英伟达。此外，V4 兼容 OpenAI 与 Anthropic 双 API 接口，便于云厂商一键接入。

### 4.5 原生 Agent 与 Harness 能力

- V4-Flash 正式版原生支持 Responses API 格式，并针对性适配 Codex 生态，一次配置即可在 Codex CLI、ChatGPT 桌面端及 VS Code Codex 插件中调用。
- V4-Pro 正式版同样原生支持 Responses API 与 Codex 适配，思考模式升级为 low / high / max 三档。
- **DeepSeek Harness**（Agent 工具链）首次亮相并即将公布，将进一步强化真实开发环境中的自主执行能力。

## 五、性能评测对比

### 5.1 V4-Flash 正式版核心跑分

以下为官方及第三方披露的基准测试成绩：

| 基准测试 | 得分 | 说明 |
|---|---|---|
| **DeepSWE（代码修复）** | **54.4** | 较预览版 7.3 暴涨超 640%（约 6 倍以上） |
| **Agent 智能体终极测试** | **25.2** | 逼近 Claude Opus 4.8 的 25.7；远高于 V4-Pro 预览版的 15.8 |
| **Terminal-Bench 2.1** | 82.7 | 终端操作能力 |
| **CyberGym（网络攻防）** | 76.7 | 安全攻防能力 |
| **Toolathlon Verified（工具调用）** | 70.3 | 工具调用可靠性 |
| **DSBench-FullStack（内部全栈开发）** | 68.7 | 真实开发环境测试 |
| **DSBench-Hard（内部高难度编码）** | 59.6 | 复杂代码专项 |

**核心亮点**：一款不到 300B 参数的轻量级模型，在多项 Agent / 编码基准上反超自家 1.6T 旗舰的预览版，部分测试逼近 Claude Opus 4.8。这标志着 AI 竞争的重心正从“更大”转向“更聪明”。

### 5.2 V4-Pro 正式版表现

V4-Pro-0813 发布后，其 Agent 能力大幅提升，9 项 Agent 基准与 Claude Fable 5 几乎持平，其中 CyberGym 达到 83.3。发布初期曾出现短暂“回滚 / 降智”争议，稳定性口碑仍待持续观察。

### 5.3 成本效率

据美国研究机构 **Artificial Analysis** 评测：

- DeepSeek-V4-Flash 每项智能指数任务的加权平均成本约为 **3 美分**，不到 Anthropic 旗舰 Claude Fable 5 的 **1/100**。
- Kimi K3 约 94 美分（Artificial Analysis 官方口径 $0.94）。
- GPT-5.6 Sol 约 1.04–1.86 美元，视不同口径而定。
- 即便与智能水平相近、已降价 80% 的 GPT-5.6 Luna 相比，V4-Flash 单任务加权成本仍约为其 60%。

### 5.4 实测反馈

多位 AI 开发者反馈，V4-Flash 正式版任务处理速度快（接入 Hermes 完成同一任务约 40 秒，GPT-5.6 Sol + Codex 约 1 分 47 秒），交付质量“在及格线之上、达到可用水平”；在国产模型中优于 GLM 5.2，但整体质量仍略逊于 GPT-5.6。由于是纯文本模型，其主要优势场景集中在推理、代码与长文档处理。

## 八、挑战与隐忧

1. **算力供给趋紧**：V4-Flash 上线后日处理量快速攀升至万亿 Token 量级，8 月 6 日 DeepSeek 突然预告“大幅涨价”，随后于 8 月 17 日正式生效。高盛研报认为，这反映国内 AI 需求旺盛、算力资源趋紧，行业竞争正从激进价格战回归理性定价。
2. **定价策略反复**：从 5 月 V4-Pro 永久降价至原价 25%，到 6 月预告峰谷定价，再到 8 月宣布整体涨价，短期定价信号频繁变动，可能影响企业的成本测算与选型信心。
3. **V4-Pro 初期稳定性争议**：正式版发布后曾出现短暂“回滚 / 降智”讨论，需要持续观察其服务稳定性与口碑修复。
4. **多模态短板**：V4 全系为纯文本模型，在图文、视频等多模态场景上落后于同期国产竞品，限制了部分应用落地。
5. **Engram 缺席**：备受期待的 Engram 记忆模块未进入 V4 架构，被部分研究者视为技术完整度上的遗憾。

## 九、总结与展望

### 9.1 核心战略判断

1. **从“堆参数”到“拼架构与后训练”**：V4-Flash 用 284B 参数在 Agent / 编码基准上反超 1.6T 旗舰预览版，证明架构设计、训练方法与推理效率同样是性能天花板的重要决定因素。
2. **从“依赖英伟达”到“降低生态依赖”**：自研算子与国产算力适配具备重要战略意义，但现阶段仍应客观表述为“降低依赖”而非“完全脱离”。
3. **从“低价倾销”到“理性定价”**：峰谷定价与整体涨价，标志着 DeepSeek 开始让价格与资本开支、算力投入相匹配。
4. **“算力平权”效应**：V4-Flash 的极致性价比（单任务成本约为 Claude Fable 5 的 1/100）大幅降低了 Agent 能力的使用门槛，使“人人都能用 Agent”成为可能。

### 9.2 后续关注问题

- V4-Pro 正式版的稳定性、后续迭代节奏与是否维持当前定价。
- 在算力趋紧与涨价预期下，DeepSeek 能否维持其“极低价格锚”的市场心智。
- 纯文本定位是否会成为其对抗多模态竞品的长期短板。
- DeepSeek Harness 工具链的正式发布与生态落地效果。
