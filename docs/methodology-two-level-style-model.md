# 两层风格模型方法论（2026-09-14，主编认可立项）

> 动机：机构有一个主导风格，但不同体裁文章各有变体。先提取机构层（跨体裁不变量），再分析体裁层（共性中的差异）。
> 教训来源：① _p2-rewrite-quality-analysis.md——build-log 体裁预算套到分析体裁导致重写降质；② 英文六库体裁路由从未运行（全部兜底 blog_or_exploration），全库聚合混入体裁构成差异。
> 地位：本文档是 P2 之后的主线框架，收编 P0-1（自有英文统计层）、P0-2（预算护栏语义）、分体裁预算三项。

## 一、模型定义

对每个指标 m、机构 L、体裁 g：

```
体裁格值    cell(L, g, m)  = median({m(a) : a ∈ L 且 genre(a) = g})     （格内 n ≥ 3 才出值）
机构层      inst(L, m)     = median({cell(L, g, m) : g 有值})           （体裁中位的中位——防主导体裁绑架）
体裁 delta  delta(L, g, m) = cell(L, g, m) − inst(L, m)
```

- **机构签名（不变量）**：跨体裁离散度低的指标——候选判定：机构内各体裁格值的 IQR/全距小于该指标的跨机构全距的一半（起点阈值，实施后校准）。这些进 playbook 的"机构签名"节，所有体裁成稿共用。
- **体裁预算**：进 playbook 各体裁条目，表达为 inst ± delta 的区间，而非全库统一区间。
- **只记录项**：跨体裁方差大且无稳定方向的指标（如数字密度）标"题材决定"，只记录不判定。

## 二、聚合纪律（在现有纪律上增补）

1. **格内 n ≥ 3** 才发布体裁预算；n < 3 的格回退到机构层区间并加宽（用全距替代 IQR），标 [小样本]。
2. **机构层不等于全库 median**——必须先格内中位、再取体裁中位的中位（体裁平衡化）。全库 median 仅作对照列保留。
3. **空格不补 0**：机构缺某体裁，机构层少一项输入，不是 0。
4. 中位数与四分位纪律、JSON 为准纪律、校准日志纪律全部继承。

## 三、跨机构比较（discriminate.py 改造方向）

1. **体裁对体裁**：只在同体裁格之间比较（A 对 A、E 对 E）；机构无该格则退出该组比较。
2. **机构层比较**：用 inst(L, m)（体裁平衡值）做机构指纹，替代当前全库 median——这分离了"写法差异"与"体裁构成差异"。
3. **FDR 族重算**：检验族按"机构层 14 指标 × 对数"与"各体裁格内 × 对数"分列，BH-FDR 分别在族内校正；报告头声明族结构。
4. 报告必须同时输出：机构层指纹 + 各机构体裁构成表（构成差异本身是事实，只是不再污染指纹）。

## 四、playbook 结构改造方向

```
机构签名（不变量，跨体裁共用）
→ 体裁路由（统一分类法，docs/genre-taxonomy-v0.md）
→ 体裁预算（inst ± delta，[小样本] 标注）
→ 操作化招式（机构层 + 体裁层分列）
```

kezhongke playbook 的 §0.2 处方走廊在自有英文统计层建立后退休为对照组（P0-1）；预算语义改护栏式（P0-2）同步并入"体裁预算"表达。

## 五、实施顺序与验证

1. 体裁分类法裁决（本文档配套 docs/genre-taxonomy-v0.md，4 项待裁决）✅ 2026-09-14 定案（见该文档 §四裁决记录）
2. LLM 路由 passe：8 库全部文章按统一分类法打标（英文 60 篇 + kezhongke 24 篇），产出 per-article genre + confidence + evidence，低置信人工裁决；回填 output JSON ✅ 2026-09-14（llm-routing-v1，93 篇全量回填 genre.unified）
3. aggregate 两层输出实现（profiler.py 或独立脚本）+ 回归测试（合成 fixture：体裁构成偏斜时 inst 不被绑架）✅ 2026-09-14（aggregate_two_level.py；tests/test_two_level.py 6 项）

5. playbook 改造（先 kezhongke 试点，再推他库）✅ kezhongke 试点 2026-09-14（templates/genre-playbook-kezhongke.md §4 两层化；改造模板沉淀 docs/playbook-two-level-template.md）。他库推广 ✅ 2026-09-14 七库全部完成（swarm 并行，各库 §3 两层化：机构层预算+分体裁 delta+旧口径留痕三节式；数值全部脚本回核 two_level JSON）。各库形态：anthropic E/G/R 三格（人称体裁极性 E16/G29/R83）；cerebras A/N 两格（设问 A3/N0 极性）；databricks N/R 两格（人称极性 N28/R15.5）；eleuther 单格出值库（仅 R n=8，signature_candidates 空，全部判定"单格出值·暂按机构层"，为模板四档之外的单格处置样例）；google-research R/N 两格（年份锚点唯一强极性）；microsoft-research N/R 两格（克制比极性 N≈11:1 vs R≈3.5:1，第一人称确认为机构不变量）；openai E/R 两格（人称 delta ±1.8 证伪旧四子体裁分档，克制比 R8.3:1/E2.6:1 方向分裂）

## 六、风险

| 风险 | 缓解 |
|---|---|
| 格内样本不足（当前 10 篇/库，分格后多格 n<3） | 回退规则 + 扩容采样（体裁平衡采样，目标 ≥20 篇/库） |
| 体裁误标污染两层结构 | LLM 路由低置信人工裁决；关键篇重跑两次不一致率 >15% 标 unstable（继承现有纪律） |
| R/N 边界模糊带体量大（google/msr） | 主编裁决边界规则；模糊篇目标注双标签倾向，敏感性分析各跑一次 |
| 检验数膨胀 | FDR 族分列 + 族内校正；探索性声明保留 |
